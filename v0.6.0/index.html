TransitionFunctionIteration.jl

TransitionFunctionIteration.jl solves discrete-time dynamic equilibrium models over a grid of states. Use it to compute policy functions, simulate a model, measure solution errors, and compare moments and impulse responses across economies.

You provide a model's parameters, equilibrium equations, exogenous Markov process, steady state and endogenous grids. The Quick Start shows how to define these for a neoclassical growth model, solve it and analyze the results.

Installation

using Pkg
Pkg.add("TransitionFunctionIteration")

Requires Julia 1.12 or later. Install StaticArrays and StructArrays as well to run the model examples and the file that generate_template writes.

How a solution is represented

A solved model is represented by functions of the state, linearly interpolated on a rectangular grid whose nodes may be unevenly spaced:

  • Pfct (policy functions): the unknowns of the equilibrium conditions at each grid point.
  • Vfct (value functions): quantities whose next-period values enter today's equilibrium conditions.
  • Tfct (transition functions): the next-period value of each endogenous state, one value per realization of the next-period exogenous state.
  • Ffct (forecasting functions, optional): current-period quantities that next period's expectations depend on besides the next-period state.

The first state variable is the index of the exogenous Markov chain. You choose the grid for each endogenous state. The solver iterates on the functions until their changes fall below the requested tolerance. Check simulated equation errors and state bounds before using a solution for analysis; Checking solution accuracy explains how.

The default method is Transition Function Iteration (TFI). Simultaneous Transition and Policy Function Iteration (STPFI) solves for policies and next-period states jointly; Choosing a solution method explains when to use it. Both support the same model interface.
