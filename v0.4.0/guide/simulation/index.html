Simulation and Analysis

Stochastic simulation

After solving with main_execute!, simulate a stochastic panel with:

simseries, errs = simulate(obj, stv)

simseries is a SimulationPanel – a StructArray of per-period NamedTuples covering all state and simulation variables defined in calc_eqm under SimulateMode. errs is a SimulationErrorPanel containing the equilibrium residuals at each simulated point, useful for assessing solution accuracy.

Key keyword arguments for simulate:

ArgumentDefaultDescription
sz10_000 => 12Periods per run => number of runs
burn500Burn-in periods discarded
seed100RNG seed for reproducibility
exog_startsteady-state indexExogenous state in the first period
endog_startstv.endogEndogenous state in the first period
dynamic_align:dropHow variables defined from consecutive periods line up (see augment_simulation)
report_boundstrueReport the ranges of the simulated states against the grid

A simulation records where it came from (the solution's id, the TFI version and the settings above) in its provenance; see Tables and Provenance.

Runs are simulated in parallel across threads, so a model's calc_eqm, augment_simulation and augment_errors must be thread-safe (no shared mutable state or global RNG use).

Computing moments

describe summarizes a SimulationPanel and returns (; moments, stderrs), each a NamedTuple of MomentArrays by sample:

out = describe(simseries)
out.moments.uncond   # MomentArray of unconditional moments

The statistics are :mean, :std, :minimum, :maximum, :ac (first-order autocorrelation), the percentiles :p5, :p25, :p50, :p75, :p95, and :cor_<state>_lag0 for each endogenous state (correlation_vars chooses the states and lags). Pass additional_stats to add statistics, either functions of one variable's series or MultivariateStatFuns that also read another variable.

Conditional moments

Pass filters as a NamedTuple of predicates, one per regime:

out = describe(simseries;
    filters = (
        uncond = Returns(true),
        crisis = x -> x.K < 0.9 * stv.endog.K,
    )
)
out.moments.uncond   # unconditional MomentArray
out.moments.crisis   # crisis-regime MomentArray

Pass dropnan=true to exclude every observation containing a NaN from all filters. A filter that selects no observations yields NaN moments rather than an error.

MomentArray access

MomentArray rows are variable names and columns are statistics. The names are part of the type, so lookup by name is resolved at compile time. Several access patterns are available:

stats = out.moments.uncond
stats(:C, :mean)                      # scalar
stats((:C, :K), :mean)                # NamedTuple of means
stats(:C, (:mean, :std))              # NamedTuple of stats for C
stats((:C, :K), (:mean, :std))        # MomentArray of the selected rows and columns
stats(Val((:C, :K)), Val((:mean,)))   # the same with the names fixed at compile time

A MomentArray also has a name for its column of row names when it is written as a table (its row key): variable for the statistics of describe, equation for calc_error_stats, moment for compare_economies. See Tables and Provenance.

Comparing economies

compare_economies builds a table of moments across economies. A moment is a lazy specification, SimulationMoment for a statistic of a simulated variable and ImpulseMoment for a point on an impulse response; the economies are describe outputs, or EconomyResults that also hold an IRF.

moment_defs = (
    MeanC = SimulationMoment(:C),
    StdK  = SimulationMoment(:K; stat=:std),
    MeanY = SimulationMoment(:Y),
)

desc_base = describe(simseries_base)
desc_alt  = describe(simseries_alt)

compare_economies(moment_defs, (; baseline=desc_base.moments, alt=desc_alt.moments))

See Moments and Comparing Economies for impulse moments, transformations, the base economy, and building the same table from saved results.

Checking solution accuracy

calc_error_stats summarizes the SimulationErrorPanel returned by simulate:

errstats = calc_error_stats(errs)

The resulting table reports max and mean absolute residuals for each equilibrium equation, evaluated at the simulated states: one row per equation (and per transition), with the mean and the percentiles :p50, :p75, :p90, :p95, :p99 and the maximum :p100 of the absolute residual. Large errors (above ~1e-4) indicate the solver may not have converged sufficiently or the grid is too coarse near the ergodic distribution. Judge accuracy by these errors, not by the convergence flag of the solver.

Impulse response functions

simulate_irf computes impulse responses by comparing simulation paths with and without a shock, holding the initial endogenous state fixed:

irf = simulate_irf(obj, simseries)

Key keyword arguments:

ArgumentDefaultDescription
T20IRF horizon (periods)
N5_000Number of draws for averaging
seed100RNG seed
shocksone per other exogenous state, plus uncondNamedTuple of forced exogenous paths: a state index or a vector of indices, e.g. (up = 5, up2 = [5, 5]); uncond = Int[] forces nothing
exog_startsteady-state indexExogenous state before the shock
path_vars()Variables whose individual draws are kept (irf_paths)
other_stats(;)Statistics besides the mean and standard deviation

endogstart, the second argument, is a NamedTuple of starting values, or a SimulationPanel, in which case the ergodic mean is used. irf is an IRFResult. Paths are indexed by shock:

propertynames(irf.means)   # the shock names, e.g. (:uncond, :shock_1, ...)
irf.means.shock_5.C        # mean C path after the exogenous state moves to state 5 (length T)
irf.stdevs.shock_5.K       # standard deviation of K across draws

The first element of a path is the starting period, before the shock. The response to a shock is the shock path compared with the uncond path; ImpulseMoment and the plot recipes do this.

Plotting

The package provides Plots.jl recipes for the main output types. Load a backend (e.g., using Plots) before calling plot.

Simulation panel scatter matrix

plot(simseries)

Produces a P×P scatter/histogram matrix of the endogenous state variables.

Simulation error grid

plot(errs, simseries)

Rows correspond to exogenous states, columns to error variables. Shows the distribution of residuals across the ergodic simulation.

Policy/value function slice

plot(obj.Pfct, :C, (; exst=3))

Plots one output variable against the remaining free state dimensions, holding all others fixed. Produces a line plot for one free dimension and a filled-contour plot for two.

IRF plots

Define the variables and transformations to display using ReportedVariable and group them into pages with IRFPage:

using TransitionFunctionIteration.Transformations

page = IRFPage([
    ReportedVariable(:C; label="Consumption", transformation=Pct()),
    ReportedVariable(:K; label="Capital",     transformation=Pct()),
    ReportedVariable(:Y; label="Output",      transformation=Pct()),
])

plot(irf, page, :A)   # IRF to the A shock

Transformations provides: Level(), Pct(), DiffLevel(), AnnPct(), and others.
